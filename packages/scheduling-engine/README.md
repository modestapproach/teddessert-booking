# @dibslist/scheduling-engine

Availability + slot-computation engine lifted from [cal.diy](https://github.com/calcom/cal.diy) (commit `180ede28`, MIT-licensed) and adapted to run standalone inside this monorepo. The core date-range math (DST `offsetDiff` correction, `.tz(tz, true)` keep-local-time override handling, half-hour-offset-zone slot rounding for zones like `Asia/Kolkata`, the two-pointer `intersect`, the interval-tree `filterRedundantDateRanges`, and the slot-boundary snapping) is preserved byte-for-byte. What's adapted on lift: all `@calcom/*` imports are stripped — the `@calcom/dayjs` wrapper is reimplemented in `src/dayjs.ts` with the same plugin set the scheduling code uses (`utc`, `timezone`, `isBetween`, `minMax`, `customParseFormat`, `duration`); Prisma `Pick<Availability, ...>` types and the `getUserAvailability` interfaces are replaced by local declarations in `src/types.ts` (`WorkingHours`, `DateOverride`, `DateRange`, `SchedulingType`, `IFromUser`/`IToUser`/`IOutOfOfficeData`); the Prisma `SchedulingType` enum and `DEFAULT_GROUP_ID` constant are inlined as string literals; `BufferedBusyTime`/`CurrentSeats` are inlined/shimmed in `src/conflicts.ts`; `getTimeZone` is inlined; and the Sentry `withReporting` wrapper around `getSlots` is dropped (its body is exported directly).
